<h1 align="center"> Student Info Card (MVVM)</h1>

<p align="center">
  A clean Flutter application built using the <strong>MVVM (Model-View-ViewModel)</strong> pattern to dynamically manage student subjects and grades.
</p>

---

## Features
* **MVVM Architecture:** Clean separation between UI views, state logic, and student data models.
* **Dynamic Subject Switching:** Cycle through enrolled subjects or view available modules at a glance.
* **Live Grade Tracking:** Increment or decrement student grades in real time with instant UI updates.

## Getting Started

Follow these steps to run the project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/koketsomatsane/student-info-mvvm.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd student-info-mvvm
   ```

3. **Install dependencies**
   ```bash
   flutter pub get
   ```

4. **Run the app**
   ```bash
   flutter run
   ```
